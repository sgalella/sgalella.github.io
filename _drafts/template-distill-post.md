## Code

```python
import numpy as np

def participation_ratio(X):
    """Linear dimensionality of a (samples x features) matrix."""
    eig = np.linalg.eigvalsh(np.cov(X, rowvar=False))
    return eig.sum() ** 2 / (eig ** 2).sum()
```
